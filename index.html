    Setup

    1. TMDB key

    Posters, genres and runtimes come from TMDB. Make a free account, then copy the API Key or API Read Access Token from themoviedb.org/settings/api.

    2. Watchlist

    Your Nov 23 export is built in. To update it, go to Letterboxd Settings → Data → Export your data and drop the ZIP or watchlist.csv here.

    3. Film details

    Once the key is in, each film is looked up on TMDB. This runs once and is remembered in this browser.
